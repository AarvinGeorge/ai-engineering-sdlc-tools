# work-log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `plugins/work-log` 0.1.0: Claude Code activity turned into dated, time-estimated, plain-language work logs, saved as a new Google Sheet per run (or a local `.xlsx` without the connector), on request or from a weekly Desktop local task.

**Architecture:** Four deterministic, stdlib-only Python scripts do the measuring and file building (`collect.py` transcripts+git → sessions JSON; `scan.py` pre-upload privacy and style scan; `workbook.py` entries JSON → `.xlsx`; `periods.py` week maths and the weekly gap finder). The skill (`SKILL.md`) has Claude do the judgement: resolve the period, merge sessions into entries, write summaries, call the Drive connector, read the sheet back. No hooks.

**Tech Stack:** Python 3.9+ standard library only at runtime (`json`, `zipfile`, `zoneinfo`, `subprocess`, `re`, `argparse`). Tests: `unittest` classes run by `pytest`; `openpyxl` is used **only in tests** to read workbooks back, and those tests skip if it is missing.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-11-05-work-log-design.md`. Where this plan and the spec differ, this plan records why (see "Deviations").
- Runtime is **standard library only** (repo design rule, `README.md` "Design rules"). No `openpyxl` import in `scripts/`.
- Default idle cutoff **15 minutes**; hours rounded to the nearest **0.25 h**; HR summaries **≤30 words**.
- "Last week" = the previous **Monday to Sunday**, local dates.
- Hours column header, verbatim: `Estimated hours (from activity)`. Manual entries' type: `Manual (hours stated)`.
- File name, verbatim: `Work log · <scope name> · <YYYY-MM-DD> to <YYYY-MM-DD>`. Folders: `Work Logs`, `Work Logs/Weekly`, `Work Logs/Manual`.
- Fixtures are **synthetic**: no real names, emails, paths under `/Users/<real user>`, or real transcript text. Use `/home/dev/...` style paths and invented projects ("Alpha app", "Beta site").
- Scripts never write prose summaries and never use the network. Exit codes: `0` ok, `1` scan hit, `2` fail-loud zero / nothing to do, `3` format change or bad input.
- Commit on branch `work-log` after each task; end messages with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Before each commit the controller greps the staged diff for `@`, key-like strings and a private list of the owner's identifiers kept outside the repo; only synthetic `example.com`/`example.invalid` addresses, regex literals, and the existing public `author` block may match.
- Test command (whole repo): `set -o pipefail; python3 -m pytest plugins -q 2>&1 | tail -3` and gate on the final `N passed` line with no `failed`/`error`.

## Deviations from the spec (decided here)

1. **No openpyxl at runtime.** `workbook.py` writes the `.xlsx` with `zipfile` + XML. Reason: the repo's "standard library only" rule; also a smaller file means a shorter base64 string for Claude to pass to `create_file`.
2. **A fourth script, `periods.py`,** for the week maths and the weekly gap finder, so they are unit-tested rather than left to the model.
3. **Scheduled runs exclude themselves.** The weekly task's instructions start with the marker `[work-log weekly run]`; `collect.py` drops sessions whose first request starts with it, so last week's log does not count the logging run as work.
4. **Read-back check after upload.** Claude compares the sheet's entry count and grand total against `workbook.py`'s printed summary. Base64 passed through a tool call can be mistyped; this catches it.

**Interfaces (Produces):**
- `wl_common.parse_ts(s: str) -> float` — ISO-8601 (with `Z` or offset) → UTC epoch seconds. Raises `ValueError` on junk.
- `wl_common.local_zone(name: str|None) -> (tzinfo, str)` — explicit IANA name → `ZoneInfo`; else `$TZ`; else the `/etc/localtime` symlink's `zoneinfo/` suffix; else `datetime.now().astimezone().tzinfo` with name `"UTC±HH:MM (fixed)"`.
- `wl_common.plugin_version() -> str` — reads `../.claude-plugin/plugin.json`.
- `wl_common.project_name(path: str, mapping: dict[str,str]) -> str` — longest-prefix match in `mapping` (keys are absolute folder paths); else: cut the path at `/.claude/worktrees/` or `/.worktrees/`; walk up to the nearest folder containing `.git` (file or dir) and use its basename; else the path's basename; replace `-`, `_`, `.` with spaces; collapse spaces; capitalise the first letter.
- `collect.active_intervals(ts: list[float], idle_s: float) -> list[tuple[float,float]]` — sort; for each consecutive pair with `0 < b-a <= idle_s` emit `(a,b)`; merge touching intervals.
- `collect.split_days(iv: tuple[float,float], tz) -> list[tuple[str,float,float]]` — split at local midnights (DST-safe: compute the next local midnight with `zoneinfo`, convert to UTC); returns `(YYYY-MM-DD, a, b)`.
- `collect.allocate(per_session: dict[str, list[tuple[float,float]]]) -> dict[str, float]` — sweep over all breakpoints; each elementary segment's length is divided equally among the sessions active in it; returns seconds per session. Invariant: `sum(result.values()) ==` length of the union of all intervals.

```python
"""Synthetic transcripts. Nothing here is real: invented paths, prompts and titles."""
import json, os, uuid

def line(type_, ts, cwd, sid, text=None, **extra):
    d = {"type": type_, "timestamp": ts, "cwd": cwd, "sessionId": sid,
         "isSidechain": False, "uuid": str(uuid.uuid4())}
    if type_ == "user":
        d["message"] = {"role": "user", "content": text if text is not None else "do the thing"}
    elif type_ == "assistant":
        d["message"] = {"role": "assistant", "content": [{"type": "text", "text": text or "done"}]}
    d.update(extra)
    return d

def session(root, slug, sid, cwd, stamps, title=None, first_prompt="build the login page", extra_lines=()):
    """stamps: ISO strings; the first is a user prompt, then alternate assistant/user."""
    os.makedirs(os.path.join(root, slug), exist_ok=True)
    rows = []
    for i, ts in enumerate(stamps):
        t = "user" if i % 2 == 0 else "assistant"
        rows.append(line(t, ts, cwd, sid, first_prompt if i == 0 else None))
    if title:
        rows.append({"type": "ai-title", "aiTitle": title, "sessionId": sid})
    rows.extend(extra_lines)
    path = os.path.join(root, slug, sid + ".jsonl")
    with open(path, "w") as fh:
        for r in rows:
            fh.write((r if isinstance(r, str) else json.dumps(r)) + "\n")
    return path
```

```python
def split_days(iv, tz):
    a, b = iv; out = []
    while a < b:
        la = datetime.fromtimestamp(a, tz)
        nxt = datetime.combine(la.date() + timedelta(days=1), time(0), tzinfo=tz).timestamp()
        end = min(b, nxt)
        out.append((la.date().isoformat(), a, end)); a = end
    return out

def allocate(per_session):
    pts = sorted({p for ivs in per_session.values() for iv in ivs for p in iv})
    got = {s: 0.0 for s in per_session}
    for x, y in zip(pts, pts[1:]):
        live = [s for s, ivs in per_session.items() if any(a <= x and y <= b for a, b in ivs)]
        for s in live: got[s] += (y - x) / len(live)
    return got
```

`parse_ts`: replace a trailing `Z` with `+00:00`, `datetime.fromisoformat`, require tzinfo (naive → `ValueError`), return `.timestamp()`. Python 3.9/3.10's `fromisoformat` rejects fractional seconds that are not 3 or 6 digits; normalise the fraction to 6 digits first.

### Task 2: `collect.py` command line — scope, sources, fail-loud rules, JSON out

**Files:**
- Modify: `plugins/work-log/scripts/collect.py`
- Test: `plugins/work-log/tests/test_collect_cli.py`

**Interfaces:**
- Consumes: Task 1 functions.
- Produces (CLI): `python3 collect.py --start YYYY-MM-DD --end YYYY-MM-DD [--scope PATH ...] [--all] [--idle-minutes 15] [--tz NAME] [--projects-dir ~/.claude/projects] [--projects-map FILE.json] [--exclude-marker "[work-log weekly run]"] [--no-git]`. Default scope is `os.getcwd()` (resolved with `realpath`). `--all` and `--scope` are mutually exclusive.
- Stdout JSON (exit 0):

```json
{"version": "0.1.0", "tz": "America/New_York", "idle_minutes": 15,
 "period": {"start": "2026-10-26", "end": "2026-11-01"},
 "scope": ["/home/dev/alpha-app"],               // or "all"
 "read": {"files": 3, "lines": 120, "partial_last_lines": 0, "skipped_types": {"ai-title": 2}},
 "earliest_activity": "2026-10-01",              // earliest user/assistant timestamp in any file read, local date
 "sessions": [{"session_id": "...", "date": "2026-10-26", "project": "Alpha app",
               "start": "10:00", "end": "11:30", "active_minutes": 45.0,
               "title": "Login page", "branches": ["main"],
               "requests": ["build the login page"], "first_cwd": "/home/dev/alpha-app"}],
 "day_totals": {"2026-10-26": 90.0},              // minutes, union across sessions
 "commits": [{"project": "Alpha app", "date": "2026-10-26", "time": "11:20", "subject": "Add login form"}]}
```

- Rules:
  - Files read: `projects_dir/*/*.jsonl` only (depth 1 under each slug). Subagent files are never read.
  - Session = one file. Its scope key is the `cwd` of its **first** `type=="user"` line. In scope when `cwd == s` or `cwd.startswith(s.rstrip("/") + "/")` for any scope `s`; `--all` matches every session.
  - Timing uses `type in ("user","assistant")` lines with `isSidechain` not true. Lines of other types are counted in `skipped_types` and ignored.
  - A user or assistant line missing `timestamp` or `cwd` → **exit 3**, stderr `format change: <file basename> line <n>: missing <field>` (first 5 hits, then a count). A JSON parse failure on any line except the file's last non-empty line → exit 3 `format change: <file basename> line <n>: not JSON`. A bad **last** line (a session still being written) is counted in `partial_last_lines` and skipped.
  - Requests: user lines whose `message.content` is a string, or a list's `text` blocks (never `tool_result`), excluding `isMeta`/`isCompactSummary` lines and text starting with `<`; stripped, cut to 300 chars, at most 20 per session-day, only those timestamped inside that day.
  - `--exclude-marker`: a session whose first request starts with the marker is dropped (default marker `[work-log weekly run]`; `--exclude-marker ""` disables).
  - Period clipping: intervals clipped to `[start 00:00 local, end+1 00:00 local)`. A session-day with 0 active seconds but ≥1 request inside the day is still emitted with `active_minutes: 0.0` (Claude may merge it).
  - Allocation runs across **all** in-scope sessions together (`collect.allocate`), then per day; `active_minutes` rounded to 0.1. `day_totals` = union per day.
  - `start`/`end` = local `HH:MM` of the first/last in-day timestamp of that session.
  - `title` = the last `aiTitle` in the file, else `null`. `branches` = sorted distinct `gitBranch` values of in-day lines.
  - Commits (unless `--no-git`): repos = distinct git top-levels (`git -C <dir> rev-parse --show-toplevel`, skipping dirs that no longer exist) of in-scope sessions' first `cwd`s, plus each `--scope` path that is inside a repo. For each: `git -C top log --all --no-merges --since=<start>T00:00 --until=<end+1>T00:00 --format=%H%x1f%aI%x1f%s`, with `--author=<git config user.email>` when that is set. Dedupe by hash. Hashes are **not** emitted. Git failures are skipped and counted in `read.git_errors`.
  - **Fail-loud zero:** if no in-scope session has any activity in the period → **exit 2**, nothing on stdout, stderr one JSON object: `{"error": "no sessions in scope for the period", "files_read": N, "sessions_total": N, "sessions_in_scope_any_date": N, "sessions_in_period_any_scope": N, "earliest_activity": "...", "commits_in_scope": N}`. Those counts are what show that the zero could have been non-zero.
  - No files at all under `projects_dir` → exit 2 with `"error": "no transcripts found"` and the directory.

- `periods.saved_weeks(titles: list[str], scope_name: str) -> set[date]` — Mondays parsed from titles exactly matching `Work log · {scope_name} · YYYY-MM-DD to YYYY-MM-DD` where start is a Monday and end = start + 6. Other titles ignored (manual entry sheets, other scopes, on-request ranges).
- `periods.missing_weeks(titles, scope_name, today, earliest: date|None, max_weeks=8) -> dict` with keys `to_create` (list of `{"start","end","title","partial": bool}`), `unrecoverable` (list of `{"start","end"}`), `already_saved` (list of start strings for the candidate window). Candidates: if no week saved, only `last_week(today)`; else every Monday after the latest saved one up to `last_week(today)`'s Monday, capped at the latest `max_weeks`. A candidate with `end < earliest` → `unrecoverable`; with `start < earliest <= end` → `to_create` with `partial: true`; `earliest is None` (no transcripts) → every candidate unrecoverable.
- CLI: `python3 periods.py last-week [--today D]` → `{"start","end"}`; `python3 periods.py missing-weeks --scope-name NAME [--today D] [--earliest D] [--titles-json FILE]` (FILE = JSON list of titles; `-` = stdin). `--today` defaults to the local date.
