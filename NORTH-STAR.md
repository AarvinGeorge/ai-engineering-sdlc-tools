# North Star

> **Changed only by the owner.** Contributors and coding agents may recommend a change, and must say
> so plainly, but never edit this file without the owner's explicit instruction. If work seems to
> need a different North Star, stop and raise it.

The owner's way of engineering with AI agents, together with a curated version of the AI
engineering SDLC industry best practices, encoded as reusable plugins, so that anyone, on any new
project, gets the same disciplined results: **reproducible, repeatable and safe**. Rules that
matter are **enforced by tools and checks, not left to the model's memory**; the model's judgement
is used only where code cannot decide.

## Properties

| Property | Done looks like |
|---|---|
| **Reusable** | A stranger installs it on a new project from this public repo and it works from the docs alone. |
| **Encodes the owner's method** | Every rule traces to a recorded engineering decision or a real incident, never invented. |
| **Captures industry best practice** | Each area names the established practice it follows and who does it, and says where the toolkit departs and why. A curated version, not a copy of everyone's. |
| **Reproducible** | The same input gives the same verdict; whatever can be computed is computed by code. |
| **Built properly** | Industry practice first, adapted on purpose; no duct tape or workarounds. |
| **Lean** | No new prose rule without retiring one or moving one into a tool; evaluation spend is scaled to the change. |
| **Proven** | Success is measured by the incidents behind the rules not recurring, and by real outside users. |

## What it is not

- Not specific to any one project: no project names, tools or decisions from elsewhere.
- Not a collection of every good idea: scope is locked per release; new ideas are parked.
- Not a survey of every vendor's practice: what it adopts is chosen and adapted.
- Not rules for their own sake.

## How it is used

Every plan and review carries one line per property (met, or weakened and why), and scope
questions are settled against it.
