# Eval coverage

Which case checks which rule. Each case is `<case>/prompt.md` plus `graders/criteria.md`; the
criterion number is the numbered item in that file. The new cases were written test-first: each is
meant to fail on the skill as it stood before the rule landed and to pass after it.

Plan-layer rules (tracker reconciliation, pause and handoff, "the plan" drawn from the plan file)
are covered by the plan-layer unit tests, not here.
